# webstats

Self-hosted аналитика сайтов без cookie. Версия 1 — Laravel + PostgreSQL.

## Быстрый старт

```bash
make up          # поднять сервисы
make migrate     # миграции
```

| Что | Адрес |
| --- | --- |
| Приложение | http://localhost:8080 |
| Письма (Mailpit) | http://localhost:8025 |
| Демо-сайт | http://localhost:8082 |

## Архитектура

Будет заполнено после этапа 1.
