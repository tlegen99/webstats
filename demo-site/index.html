Демо-магазин для проверки трекера Webstats. Каждое действие на сайте отправляет событие.

Перейти в каталог

Что проверить

  • Обычный переход — событие pageview.
  • Кнопка «Подписаться на скидки» — своё событие newsletter_click.
  • Внешняя ссылка — событие outbound.
  • Ссылка с UTM-метками — источник «Telegram».
  • Несуществующая страница — событие 404.
  • Переключите вкладку браузера и вернитесь — событие engagement со временем на странице.

С атрибутом data-debug каждое событие видно в консоли браузера, а запросы — во вкладке Network.
